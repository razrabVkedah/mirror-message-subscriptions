# Mirror Message Subscriptions

Сервис подписок на сообщения Mirror. Сервер отправляет сообщение только тем клиентам, которые на него подписались.

## Версии

- Unity 2022.3.62f3
- Mirror 96.0.1
- Extenject 9.2.0

## Запуск

1. Открыть сцену `Assets/_Project/Scenes/Main.unity`.
2. В редакторе Unity запустить сцену и нажать `Host (Server + Client)`.
3. Собрать и запустить Windows-билд.
4. В билде указать адрес и порт в формате `127.0.0.1:7777`, затем нажать `Client`.
5. На клиенте нажать `Subscribe to HelloMessage`.
6. На хосте нажать `Send HelloMessage`.

На подписанном клиенте появится `Последнее сообщение: Hello Client!`.

Для проверки фильтрации подключите второго клиента, но не нажимайте подписку: сообщение он не получит и останется подключённым.

Кнопка подписки появляется после подключения клиента, а отправка сообщения — после запуска сервера. Если выбранный для Host порт занят, текст ошибки появится в статусе интерфейса.

## Как устроено

`MessageSubscriptionRegistry` хранит подписки по `connectionId`. `MirrorMessageService` принимает запрос подписки и отправляет сообщения только подходящим соединениям. Повторная подписка не создаёт дубликатов, а при отключении клиента его подписки удаляются.
